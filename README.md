# Samuel — Portfolio (Flutter Web)

Lancer : `flutter pub get` puis `flutter run -d chrome`
Publier : `flutter build web` (dossier `build/web`) -> Firebase Hosting, Netlify, GitHub Pages...

## Où modifier
- `lib/data/model_data.dart` : textes, mensurations, email, Instagram, liste des photos
- `assets/images/` : ajoute tes photos, puis déclare-les dans `photos`
- `lib/constants.dart` : couleurs (kNavy, kBlue, kSky, kIce) et menu
- `lib/pages/portfolio_page.dart` : mise en page des sections
